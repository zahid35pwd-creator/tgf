# বেতন হিসাব — Salary calculator prototype

সরকারি চাকরিজীবীদের বেতন, ভাতা, কর্তন, ইনক্রিমেন্ট ও পেনশন হিসাবের একটি
স্ট্যাটিক ওয়েব প্রোটোটাইপ। কোনো বিল্ড টুল বা সার্ভার লাগে না — যেকোনো
স্ট্যাটিক হোস্টে ফোল্ডারটি রাখলেই চলবে।

## গুরুত্বপূর্ণ নোট (এই প্রোটোটাইপের ভিত্তি)

এই সেশনের নেটওয়ার্ক নীতিমালা `salarybd.online` ডোমেইনে সংযোগ ব্লক করেছে
(egress proxy → HTTP 403), তাই মূল সাইটের পেজ, ফর্ম বা অভ্যন্তরীণ কোড পড়া
সম্ভব হয়নি। ফলে এখানকার পেজ কাঠামো ও হিসাবের যুক্তি জাতীয় বেতন স্কেলের
প্রচলিত নিয়ম থেকে পুনর্গঠিত — মূল সাইটের সাথে এক এক করে মিলিয়ে যাচাই করা
হয়নি। মূল সাইটের সাথে হুবহু মেলাতে হলে ডোমেইনটি অনুমোদিত হওয়ার পর
`assets/js/data.js` ও পেজগুলোর ফিল্ড তালিকা হালনাগাদ করতে হবে।

## পেজসমূহ

| ফাইল | বিষয় |
|---|---|
| `index.html` | হোম — ফিচার তালিকা ও প্রবেশপথ |
| `calculator.html` | মাসিক বেতন: ভাতা, কর্তন, আয়কর, বোনাস, নিট বেতন |
| `payscale.html` | ১–২০ নং গ্রেডের সব ধাপের মূল বেতন টেবিল |
| `increment.html` | বার্ষিক ৫% ইনক্রিমেন্টের প্রক্ষেপণ |
| `pension.html` | পেনশন, সমর্পণ ও আনুতোষিক |
| `about.html` | ব্যবহৃত হার ও দাবিত্যাগ |

## কোড কাঠামো

```
assets/js/data.js   সব হার, স্কেল ও নিয়ম (একমাত্র উৎস)
assets/js/calc.js   বিশুদ্ধ হিসাব ফাংশন — DOM-নিরপেক্ষ, Node-এও চলে
assets/js/ui.js     ফর্ম ↔ ফলাফল সংযোগ, বাংলা সংখ্যা, থিম, মেনু
assets/css/style.css  ডিজাইন সিস্টেম (লাইট ও ডার্ক)
tests/calc.test.js  হিসাবের পরীক্ষা
```

হারের কোনো সংখ্যা `calc.js` বা HTML-এ বসানো নেই। প্রজ্ঞাপনে হার বদলালে শুধু
`data.js` সম্পাদনা করলেই পুরো সাইট হালনাগাদ হয়।

## চালানো ও পরীক্ষা

```bash
python3 -m http.server 8777      # তারপর http://127.0.0.1:8777/
node tests/calc.test.js          # হিসাবের পরীক্ষা
```

## হিসাবের ভিত্তি

- বার্ষিক ইনক্রিমেন্ট মূল বেতনের ৫%, গ্রেডের সর্বোচ্চ সীমায় থেমে যায়।
- বাড়ি ভাড়া এলাকা ও মূল বেতনের স্তরভেদে শতকরা হারে, প্রতিটি স্তরে একটি
  সর্বনিম্ন টাকার সীমা আছে।
- উৎসব ভাতা মূল বেতনের ১০০% (বছরে ২ বার), বৈশাখী ভাতা ২০%।
- আয়কর: বেতন খাতে অব্যাহতি (মোট আয়ের ⅓ বা সর্বোচ্চ সীমা, যেটি কম) বাদ দিয়ে
  স্ল্যাব অনুযায়ী; বিনিয়োগজনিত রেয়াত ধরা হয়নি।
- পেনশন: চাকরিকাল অনুযায়ী হার (৫ বছরে ২১% থেকে ২৫ বছরে ৯০%), অর্ধেক সমর্পণে
  প্রতি ১ টাকায় ২৩০ টাকা আনুতোষিক।

সব হার প্রজ্ঞাপনভেদে পরিবর্তনশীল। এটি সরকারি সাইট নয়; চূড়ান্ত হিসাবের জন্য
নিজ দপ্তরের হিসাবরক্ষণ কর্মকর্তার সাথে মিলিয়ে নিন।
